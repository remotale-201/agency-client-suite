💡 System Architecture Summary
Remotale is designed with dual-access visibility: Super Admins oversee all client portfolios, create deliverables, and track revenue, while Clients log in to an isolated, secure workspace showing exclusively their projects, credentials, and billing.

1.2 Signing In Step-by-Step

1

Open the Remotale Application

Navigate to the web address or mobile URL. The sign-in screen presents two clean fields: Username and Password.

2

Enter Your Credentials or Use Quick-Fill

Type your assigned username and password. For rapid testing, click any pill button (e.g. "Awais (Remotale123)") to auto-fill credentials instantly.

3

Click "Sign In"

The system validates your account against the PostgreSQL database and immediately opens your customized dashboard.

🔒 Security Notice
Always click Log Out from the user profile dropdown or top-bar before closing your browser session on shared devices.
Module 02

Executive Dashboard & Live Tracking

The dashboard serves as the central control room. It consolidates key operational KPIs, upcoming deadlines, recent team activities, and project statuses into one view.

2.1 Key Metrics Overview Cards

📁

Active Projects Card

Displays total projects currently active in the system, with percentage variance from the preceding week.

✅

Completed Deliverables

Summarizes total finished milestones and 100% delivered customer projects.

💰

Financial / Budget KPI

For Admins: Total agency revenue. For Clients: Total allocated budget across active contracts.

⚡

Team Capacity & Tasks

Real-time metric of tasks in flight and available capacity of lead project engineers.

2.2 Interactive Dashboard Controls

📅

Dynamic Date Filter Dropdown

Located in the top right. Click the calendar pill to toggle between Today, This Week, This Month, or select a custom date using the calendar picker.

🚀

Recent Projects Quick Access

Click any project row in the dashboard to launch the Project Detail Workspace instantly with full task checklist and credentials.

⏰

Upcoming Deadlines Widget

Highlights deliverables due within the next 7 days with dynamic badges: Due in 2 days, Due tomorrow, or On track.

Module 03

Project Management & Workflow

The My Projects view allows you to search, filter, create, edit, and organize all deliverables with categorized badges and progress tracking.

3.1 Filter Tabs & Search Controls

1

Status Filter Pills

Switch between All Projects, In Progress, Under Review, and Completed. Each pill shows a live numerical counter badge.

2

Real-time Search Bar

Type any keyword (e.g. "White Label" or "Fytnex") to filter matching projects instantly across titles, descriptions, and tags.

3

Sort By Toggle

Click the sort button to arrange deliverables by Latest Created or Progress Percentage.

3.3 Creating or Editing a Project

Click "+ Add Project" at top right. Fill in Title, Description, Type, Deadline, Budget, and (for Admins) assign the Client. Click "Create Project" to save to the database.

Module 04

Deep-Dive Workspace (Detail View)

Clicking any project card opens the full ProjectDetailWorkspace. This view is divided into 5 focused tabs:

📄

Tab 1: Overview

Displays full project specifications, start and end dates, priority level, assigned Admin Lead (Abdullah), and calculated live progress.

☑️

Tab 2: To Do List (Interactive Checklist)

Tick any task checkbox to instantly toggle completion. The project progress bar updates in real time. Click "+ Add Task" to insert new tasks with target deadlines.

📁

Tab 3: Files & Assets

Repository of deliverables including Figma mockups (.fig), zip packages (.zip), RAR brand kits, and preview links. Click the download icon on any row to retrieve files.

🔐

Tab 4: Credentials Vault (Encrypted Platform Logins)

Secure repository for store admin logins (Shopify, WordPress, cPanel). Features One-Click Copy for usernames and passwords with visual checkmark confirmation.

📝

Tab 5: Notepad (Shared Briefs)

Bulleted project requirements and notes. Click "Edit" to update notes with zero latency and automatic cloud sync.

💡 One-Click Credentials Copying
In the Credentials tab, clicking the copy icon next to any username or password copies the value directly to your device clipboard for instant pasting into Shopify Admin or CMS portals.
Module 05

Invoices & Financial Management

The Invoices View provides agency-grade billing transparency. Both Admins and Clients can view payment histories, outstanding balances, and official invoices.

5.1 Financial Summary Cards

💳

Total Billed

Gross amount of all invoices generated across projects.

🟢

Paid to Date

Total confirmed cleared payments received.

🟡

Outstanding Balance

Pending dues awaiting settlement before milestone release.

🔴

Overdue Amount

Invoices past their designated due dates flagged for follow-up.

5.2 Managing Invoices

1

Filter by Status

Click tabs: All Invoices, Paid, Pending, or Overdue to isolate specific billing states.

2

Create New Invoices (Admins)

Click "+ Create Invoice". Select Client, due date, enter line items with unit prices and quantities. Tax and discounts are automatically calculated.

3

View / Download PDF Invoices

Click "Download" on any invoice row to export the branded invoice for accounting and tax records.
